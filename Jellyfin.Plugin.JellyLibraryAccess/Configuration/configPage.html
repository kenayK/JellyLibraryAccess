JellyLibraryAccess

Approve individual movies without moving or duplicating files. The plugin uses Jellyfin's Allowed Tags filter underneath and keeps approvals attached to TMDb/IMDb IDs so Radarr upgrades are safe.

Libraries already safe for the kids

Select the existing Kids Movies library (and any other libraries the child should always retain). The plugin automatically applies the approval tag to every movie in these libraries.

One-time child user setup

In Dashboard → Users → your child: give access to both Kids Movies and Movies, then set Allowed Tags to the approval tag above. All normal Movies remain hidden because they do not carry that tag; the Kids Movies library remains visible because this plugin keeps it tagged automatically.
