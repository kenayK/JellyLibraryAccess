JellyLibraryAccess

Approve individual movies for a restricted profile without moving or duplicating files. The plugin uses Jellyfin's Allowed Tags filter and keeps approvals attached to TMDb/IMDb IDs so Radarr upgrades are safe.

Default: jellylibraryaccess-approved. You can change this to suit your server.

Baseline libraries

Select libraries this restricted profile should always retain, such as Kids Movies. The plugin automatically applies the approval tag to every movie in these libraries.

One-time restricted user setup

In Dashboard → Users → the restricted profile: give access to both the baseline library and any other library from which you want to approve individual titles, then set Allowed Tags to the approval tag above. Unapproved movies remain hidden because they do not carry that tag; baseline libraries remain visible because this plugin keeps them tagged automatically.
